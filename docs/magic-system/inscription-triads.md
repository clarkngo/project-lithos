# Inscription triads

An **inscription** is one locked triad: Form Vector + Affinity Cadence + optional Mutator Node.

The names **Talon Vector**, **Barrow Vector**, **Ember Cadence**, **Marsh Cadence**, **Gross Node**, and **Feral Node** appear in the project's terminology lexicon as examples. Everything in the tables below is an **illustrative working set** for the Codex calculator and for `tools/resonance-engine`. It is not a complete in-world catalog.

## Form Vectors (slot 1)

| ID | Name | Skeletal scaffold | Tissue stress (typical) |
|---|---|---|---|
| `talon` | Talon Vector | Raptorial: hooked digits, hollow-bone bias, striking posture | Nail beds, distal joints, wrists |
| `barrow` | Barrow Vector | Subterranean: heavy-set, load-bearing, burrowing posture | Shoulders, spine, finger bones |
| `ridge` | Ridge Vector | Plated: weight-bearing spinal shelf, braced stance | Scapulae, lumbar fascia |

`ridge` is an extra illustrative example, not attested in the lexicon.

## Affinity Cadences (slot 2)

| ID | Name | Breath / temperament | Thermal profile |
|---|---|---|---|
| `ember` | Ember Cadence | Heat, combustion, short-fuse temperament | Violent overshoot, then crash |
| `marsh` | Marsh Cadence | Wet weight, anaerobic drag, slow temperament | Low smolder, long wet chill after |
| `gale` | Gale Cadence | Pressure, thin air, restless temperament | Fast heat-loss; shaking, not fever |

`gale` is an extra illustrative example, not attested in the lexicon.

## Mutator Nodes (slot 3, optional)

| ID | Name | Distortion | Drift tendency |
|---|---|---|---|
| `gross` | Gross Node | Scales mass — more body to feed, more body to tear | Moderate: weight dulls some instinct, not hunger |
| `feral` | Feral Node | Instinct-dominance — the Shift thinks faster than the name | High: predatory affect arrives early |
| `hollow` | Hollow Node | Reduces density — less mass, worse cold, worse aftershock | Moderate: identity thins with the bones |

`hollow` is an extra illustrative example, not attested in the lexicon.

## Reading a triad

**Talon + Ember** is a striking, heat-bright raptor shape. Add **Feral** and the instinct arrives before the hands remember they were hands. Add nothing, and the body still pays caloric debt, tearing, and hypothermia — the Node only changes the *shape* of the bill, not whether there is one.
